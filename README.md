## 课题锚点

**基于平扫 CT 影像组学与深度学习融合模型的 ASBO 三分类治疗决策研究**

核心链条：CT 诊断 / 影像组学 / 深度学习 → 预测模型 / 可解释性 AI → 保守治疗 / 手术治疗 / 肠切除术三路径决策。

## 知识图谱 Schema（五层 + 扩展）

- **病理生理层**：粘连形成、肠绞窄、肠缺血、肠坏死、闭袢性梗阻等
- **影像征象层**：移行带、鸟嘴征、漩涡征、靶征、肠壁积气等
- **检验指标层**：CRP、白细胞计数、乳酸、D-二聚体等
- **处置策略层**：保守治疗、水溶性造影剂、手术治疗、肠切除术等
- **预后结局层**：复发、死亡率、并发症、住院时长
- **扩展层**：方法学（影像组学/深度学习）、诊断技术、指南机构

## 使用方法

1. 安装 [Obsidian](https://obsidian.md)
2. 「打开本地仓库」→ 选择本文件夹
3. 左侧打开「Graph View」浏览知识网络；从 `00_导航/00_总览MOC` 开始导航
